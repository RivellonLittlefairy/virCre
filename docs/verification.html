排查发现与修正

  1. ActivityThread 的 system context 经 createPackageContext 后，getPackageName 虽为 com.android.shell，AttributionSource 却仍归属 android，触发“No association with ID”。现显式使用真实 UID 2000 与真实 shell 包；VDM 的 UID/包归属校验仍执行。
  2. CameraService 会为虚拟设备将后置/前置相机分别映射到 0 / 1。注册返回值和 App 枚举值不同；日志分别保留两者。
  3. 应用 logcat 未提供可用输出，改用 App 私有 JSONL 元数据文件。文件不含相机像素。
  4. 代码审查发现元数据被转成 marker 0 的假阳性风险，以及同步 ADB 可能无期限等待。已新增回归测试，证据现在严格筛选 frame-read，校验会话/设备/显示/相机/时间戳，ADB 子进程有超时。
  5. 一次无线 ADB 中断造成关联与临时文件的 finally 清理失败；重连后针对该会话手动清理，并确认 VDM 无活动实验设备。日志保留真实清理失败，未覆盖为成功。
