scrcpy 修改记录

2026-10-20。上游：Genymobile/scrcpy 5.0.1，提交 a60891aea193d92e7e5c3942700eca63f9d19a5f。上游许可 Apache 2.0；保留 Genymobile 和 Romain Vimont 的原始版权。本项目是独立修改版。

主要改动

  • Windows 输入法：观察组词状态，过滤对应按键，保留普通英文路径，通过带序号协议提交 Unicode。
  • 手机输入事务：跨 shell 进程串行执行剪贴板设置与 Ctrl+V，返回派发确认或拒绝，避免失败重播和文本日志。
  • Android 16 虚拟设备：把 camera-agent 接入 server，在同一虚拟设备中创建相机和应用显示，将显示直接连接 scrcpy 编码 Surface。
  • Windows 桌面输入：排除投屏窗口自身，拖动或缩放时继续消费和渲染最新帧，并处理帧事件合并。
  • 条件变量超时修正、参数与协议检查、构建配置及配套测试。

相机只作用于相应虚拟设备内的应用；输入确认只表示系统派发完成。原创 camera-agent 源码同时在对应项目源码快照中提供。
