这是阶段一的界面预览。应用卡片均为示例，使用 demo.* 包名；不会连接手机或打开手机 App。搜索、临时收藏、导航和外观设置用于体验真实 WinUI 3 界面。

启动

cd C:\Users\msf\AndroidStudioProjects\virCre
pwsh -File .\tools\Start-Desktop.ps1
# 已构建后直接启动：
pwsh -File .\tools\Start-Desktop.ps1 -NoBuild

要求 Windows x64、Windows 10 2004（build 19041）或以上；从源码构建需要 .NET 8 SDK、NuGet 网络访问及 PowerShell 7。本机已使用 .NET SDK 8.0.419 构建。WinUI 3 依赖 Windows App SDK 1.8.260921001 与 Windows SDK BuildTools 10.0.26100.9169；项目按未打包自包含方式生成，不依赖全局安装 Windows App Runtime。

本阶段可体验的内容

  • 全部应用：8 张示例卡片、中文名称与包名搜索，清空搜索恢复全部。
  • 收藏：点星标加入或取消；收藏页数量与空状态同步。收藏只在本次进程内生效。
  • 运行中：显示尚未打开应用的空状态，不伪造运行中的手机 App。
  • 设置：跟随系统、浅色和深色主题；主题只在本次运行内生效。
  • 连接手机、打开应用保持禁用，主界面持续显示未连接和示例说明。
