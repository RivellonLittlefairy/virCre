virCre 应用图标设计

采用用户确认的蓝青色几何窗口方案：桌面窗口与手机轮廓交叠，表达在电脑上独立使用手机应用的核心功能。图标不使用文字，也不以摄像头作为主要符号。

使用 app-icon-prompt 技能整理设计方向，再通过内置 image_gen 工具生成和精修 PNG。源图保留透明通道，使用等比例缩放导出 Windows 多尺寸资源。

项目资源

  • desktop/VirCre.Desktop/Assets/Brand/vircre-icon-source.png：生成的高分辨率透明源图。
  • desktop/VirCre.Desktop/Assets/Brand/vircre-icon-256.png：窗口标题栏使用的 PNG。
  • desktop/VirCre.Desktop/Assets/Brand/vircre.ico：包含 16、20、24、32、40、48、64、96、128、256 像素的 Windows 图标。
  • tools/Build-AppIcon.ps1：从源图重新导出 PNG 和 ICO，仅执行尺寸与格式转换。

接入位置

项目通过 ApplicationIcon 将图标嵌入 EXE，通过 AppWindow.SetIcon 设置窗口和任务栏图标，标题栏使用相同设计的 PNG。Inno Setup 的 SetupIconFile 使用发布目录中的同一 ICO；开始菜单、桌面程序快捷方式和卸载入口从 EXE 读取图标。手机应用快捷方式继续使用各手机应用自身的图标。

可在项目根目录运行 pwsh -NoProfile -File tools/Build-AppIcon.ps1 重新导出，再按 Windows 打包说明编译。源图只用于设计和构建，运行时仅需 ICO 与 256 像素 PNG。Windows 可能缓存旧快捷方式图标，已有快捷方式显示情况需在更新程序后手动确认。

生成提示

Use case: logo-brand. Asset type: production Windows desktop application icon for virCre, a WinUI 3 tool that lets Android phone apps run in independent PC windows. Create ONE finished icon, no contact sheet or mockup. Primary concept approved by user: blue and cyan geometric windows, merging a phone silhouette and desktop app window in a simple, distinctive mark. Design a bold compact front-facing emblem: a thick deep cobalt rounded rectangular desktop-window outline with a small horizontal top bar, seamlessly interlocked with a narrower upright cyan/teal phone-shaped window at the lower-right, sharing part of their contour so it feels one integrated symbol. Use strong clean geometry, generous negative space, broad strokes and a recognisable silhouette that reads at 16px and 32px. Modern restrained Fluent-compatible flat vector-like finish, subtle blue-to-cyan tonal variation only, no 3D perspective, no glass blur, no thin decorative details. Palette cobalt #2563EB, azure #168BEA, cyan #21C8D4. Exactly square 2048x2048 source canvas if supported, emblem centered, bounding box about 78% of canvas with clear safe margins. Transparent background, genuine alpha outside the symbol and inside the open window cutouts. No enclosing rounded-square app tile, no opaque backdrop, no surrounding scene, no text, no lettering, no watermark.

Refine this exact approved virCre app icon into a final clean production asset.
