下载与升级

安装版：virCre-0.2.3-win-x64-setup.exe；便携版：virCre-0.2.3-win-x64-portable.zip；校验文件：virCre-0.2.3-SHA256SUMS.txt。

升级前关闭 virCre 及其手机应用窗口。便携版需完整解压并保留整个目录；移动程序目录后需重新创建手机应用快捷方式。
