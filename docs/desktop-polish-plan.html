真实图标、设置与快捷方式

目标：让真实手机应用容易辨认，收藏和主题跨重启保存，支持把应用拖到 Windows 桌面生成快捷方式。按用户授权依次实现，沿用当前功能分支，不修改用户 Android 构建配置。

一、真实图标

独立的小型 Java shell 入口，通过已授权 ADB 推送 dex，使用 PackageManager 读取指定应用的图标并在 Android 渲染为 96×96 PNG。无需安装 APK、root 或修改第三方应用。按设备隔离缓存，每次刷新重新获取；读取失败只影响图标，不阻止应用目录。代际和取消约束沿用目录控制器。

新增 android-agent 图标入口与构建脚本；Launcher 的 IconCatalog 装饰现有目录服务；PhoneApp/AppCard 增加图标路径，WinUI 显示 PNG 并保留失败占位。测试覆盖协议校验、设备隔离、取消与目录降级；真机检查 PNG 和实际界面。

二、收藏和主题保存

SettingsStore 在 %LOCALAPPDATA%\virCre\settings.json 保存收藏包名和主题。原子替换，缺失使用默认值；损坏使用默认值并提示，保留原文件以便排查。写入串行化，退出等待写入结束；失败保持内存状态并明确提示。收藏按包名跨手机共享，只显示当前安装的应用。

测试覆盖 Unicode、重启恢复、损坏配置、未知版本、并发保存与失败。UI 删除“仅本次有效”说明，启动恢复主题。

三、桌面快捷方式

应用卡片支持拖出 PNG 图标对应的 .lnk 文件，另提供右键“创建桌面快捷方式”。链接指向当前 virCre 可执行文件，使用结构化编码参数携带设备标识、精确包名和名称，禁止 shell 拼接。使用手机硬件序列号识别无线 ADB 地址变化；无法读取稳定硬件标识时拒绝创建和自动启动，避免旧网络地址被另一手机复用。

快捷方式双击启动主界面，自动查找对应在线手机、检查应用是否仍安装并开独立窗口。已有主程序使用单实例激活转发以复用窗口管理。离线、不匹配、卸载和参数损坏均显示错误，不自动授权。链接图标保存在持久缓存目录，每台手机保留上一代及当前 PNG 缓存；拖拽中间目录最多保留 30 次，并清理超过 7 天的目录；软件移动后需重建快捷方式。

测试覆盖编码/验证、设备选择、.ico/.lnk 文件读取、单实例转发；真机通过链接打开设置并确认重复打开复用。拖拽交互通过真实 Windows 桌面核对。
