电脑中文输入预览版

日期：2026-10-19。此版交给用户手动验收。按用户要求，本次仅修改源码、编译及打包，不运行自动化测试、不操作手机、不启动测试窗口；新增的 ImeProbeActivity 测试页面与窗口输入脚本已移除，不需要安装测试 APK。

如何使用

  1. 正常退出旧版 virCre，并关闭旧版打开的手机应用窗口。主程序使用单实例激活，旧版未退出时，打开预览版可能仍回到旧版。
  2. 打开 out\desktop-ime-preview\VirCre.Desktop.exe。保留整个发布文件夹，无需管理员权限，也无需另装 scrcpy。
  3. 连接手机，从应用列表打开你平时使用的应用。点击该应用输入框，切到电脑上的中文输入法，正常组词、选词和输入。

预览包已带配套的自定义 scrcpy 客户端、server、ADB 和运行库；从预览版打开的独立应用窗口会启用 --windows-ime。已有的 out\desktop-release 保持原版组件，便于对照。

手动检查

  • 中文候选框显示、空格或数字选词后上屏，是否出现多余拼音或重复字符。
  • 英文数字、中英文混输、标点、emoji、退格、回车、取消组词以及普通复制粘贴。
  • 两个应用窗口交替输入，观察是否有漏字、乱序或文字进入另一个窗口。

本次崩溃处理

旧日志包含 Android 同步粘贴失败、控制通道退出，以及 Windows 客户端条件变量超时断言失败。源码现在在 SDL 提前报告超时时重新核对单调时钟，保留真实截止时间检查；控制线程退出后拒绝新消息并唤醒等待。

无输入焦点或 Android 拒绝粘贴时，server 返回独立失败消息，客户端保留应用窗口，并在标题显示“输入未确认”。队列满或文字超出单条 64 KiB 限制也显示失败。失败文字不会自动重发；请先核对输入框内已有内容，再重新输入。成功派发后恢复原窗口标题。连接丢失或确认超时仍按会话故障处理。

实现范围与待验收项

Windows 原生输入法负责组词；已确认的 Unicode 通过控制通道发往手机，并使用手机剪贴板同步粘贴。不读写 Windows 剪贴板来传递 IME 文本，不记录输入内容。手机剪贴板会保存最近提交的文字；所有自定义 server 会过滤专用标签，避免将该内容自动同步回电脑。

禁止粘贴的应用或密码框可能不支持。同步派发确认只表示系统处理了按键，不保证每个 App 都接收文字。候选框使用窗口内固定锚点，暂不跟随 Android 光标。

当前不能标记“自然中文输入已验证”或“崩溃已复测修复”；本轮实际输入和稳定性均等待用户反馈。
