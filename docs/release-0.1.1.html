virCre 0.1.1

2026-10-20。应用版本为 0.1.1，Windows 文件与程序集版本为 0.1.1.0。

功能调整

  • 桌面快捷方式可直接打开手机应用。通过链接启动时主界面保持隐藏，不加载完整应用目录；最后一个应用窗口关闭后结束后台会话。连接失败时显示主界面和原因。旧测试目录中的链接需在新版重新创建。
  • 新窗口使用手机主屏的尺寸和DPI，跟随手机自然方向的比例，初始窗口适应电脑可用空间；不再固定1440×2560或720×1280窗口。虚拟摄像头沿用实际虚拟显示尺寸，编码器可能做少量像素对齐。

可靠性修复

  • 隔离窗口事件订阅者异常，锁外通知，保证启动失败可以结束等待；保留未完成关闭工作的进程归属。
  • 关闭等待增加15秒上限，超时恢复收尾界面，重试复用未完成的清理任务。
  • 快捷方式复制成功后删除临时文件；回退链接正常可写时新旧格式合计保留最多30次、最长7天。已知图标丢失时提示刷新，避免静默生成默认图标。
  • 目录格式异常增加来源标记，缩小全局恢复范围并清空过期设备选择；拖拽结束始终释放指针捕获。
  • Android EGL逐流、逐资源清理，单个释放或诊断失败不跳过后续资源；保留进程硬截止兜底。

关面板与点击诊断

新窗口启用虚拟显示保活。手机亮屏解锁后，在电脑应用窗口按左Alt+O，可关闭手机面板，并在此会话中额外维持主屏交互；在原窗口按左Alt+Shift+O恢复面板。用户已确认，这种面板黑色状态下，B站个人页按钮仍可点击。

面板关闭不等于锁屏。程序不自动唤醒或解锁、不修改系统超时；每4秒观察到主屏休眠时取消额外保活。多个窗口共享物理面板，某个会话恢复或退出可能影响其他窗口的关面板意图。有限诊断只记录固定触控与电源阶段，不记录坐标、输入文字或页面内容。

暂缓项：手机真正休眠或锁屏时，部分App控件仍可能不响应，尚未定位到具体控件处理机制。本轮按用户要求停止继续排查；未实现VirtualTouchscreen输入后端，也不宣称已修复所有App的锁屏交互。

本次提交前的桌面Release编译通过（0警告、0错误），已核对编译后文件版本0.1.1.0；内置scrcpy/Java Release编译通过，19个运行时文件的SHA256与manifest一致，PowerShell安装器脚本语法和git diff --check通过。按用户要求，不自动运行测试、GUI、安装器或手机操作。关面板点击的结果来自用户手动验证，不代表全部设备、App或真正锁屏场景均已通过。
