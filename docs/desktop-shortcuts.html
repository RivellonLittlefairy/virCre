手机应用，拖到桌面

应用列表显示手机中的原始图标，收藏和主题在重启后保留。把应用卡片拖到桌面，或右键选择“创建桌面快捷方式”，即可生成带应用图标的 Windows 快捷方式。

使用

  1. 连接 Android 16 手机，完成 ADB 调试授权。请保留完整发布目录；ADB 和 scrcpy 已内置，不需要单独安装或配置 PATH。
  2. 启动 VirCre.Desktop.exe，选择手机并等待列表与真实图标加载。点击星标收藏，设置页可选系统、浅色或深色主题。
  3. 从卡片的图标、名称或空白区域拖到桌面空白处；不要从星标或“打开应用”按钮起拖。也可以右键卡片选择“创建桌面快捷方式”。
  4. 双击桌面的快捷方式，virCre 自动识别对应手机，直接打开该应用的独立窗口，无需先打开主界面。通过快捷方式启动时，主界面保持隐藏，不读取完整应用列表；后台只保留设备和窗口会话，最后一个应用窗口关闭后自动退出。主程序已运行时复用原进程；同设备同应用已打开时切回原窗口。
  5. 手机离线、未授权、应用已卸载或快捷方式参数损坏时，再显示主界面和原因。在后台会话期间正常启动 virCre，可打开应用目录并继续管理窗口。它不会替用户确认手机权限或配对。

无线 ADB 地址变化时使用手机硬件标识重新匹配。无法读取稳定标识的手机暂不能创建自动连接快捷方式，避免误连另一手机。程序目录应固定；移动或删除该目录后，需重新创建链接。从旧测试目录改用安装版或新发布目录时，也需在新版里重新创建快捷方式；旧链接仍会运行原目录中的版本。快捷方式不会把 Android 应用安装到 Windows，也不复制应用账号或数据。

设置与缓存

位置用途
%LOCALAPPDATA%\virCre\settings.json收藏包名、主题和格式版本；串行原子写入，损坏时使用默认值并提示。收藏跨手机共用，只展示当前已安装的匹配应用。
%LOCALAPPDATA%\virCre\app-catalog\icons96×96 PNG，按内容SHA256持久保存，刷新不删除仍被卡片引用的旧图标。与手机主题包不同，使用应用自身资源；个别异常图标降级占位。已知图标文件丢失时，创建快捷方式会提示刷新，避免静默生成默认图标。
%LOCALAPPDATA%\virCre\shell\shortcut-icons\链接引用的 ICO，按图标内容去重并持久保存。删除这些文件会让已有快捷方式失去图标。
%LOCALAPPDATA%\virCre\shell\drag\拖拽生成的临时 .lnk；每次拖拽清理，最多保留 30 次，并清理超过 7 天的中间目录。桌面复制出来的链接不受影响。
%LOCALAPPDATA%\virCre\shell\shortcuts\桌面复制成功后删除中间链接；桌面不可写时保留回退文件。每次创建时清理，正常可写时新旧格式合计最多30次、最长7天；IO失败保留文件并记录，不递归删除未知目录。

程序会通过已授权 ADB 推送一个只读 dex 图标导出器，无需安装 APK 或 root。PackageManager 读取图标资源，Android Canvas 渲染 PNG 后传回 Windows。命令完成后删除手机临时 jar；本地读取有超时，手机进程也有 45 秒自退出保护。它不会修改手机系统主题、全局权限或第三方 APK。

手机关屏与点击响应

若手机按电源键息屏后，电脑窗口中的部分按钮不响应，请先正常亮屏解锁。在电脑应用窗口按左Alt+O，只关闭手机物理面板并保持交互；在原窗口按左Alt+Shift+O恢复面板并结束该会话的主屏保活。新窗口启用虚拟显示保活，只有明确关闭面板后才额外维持主屏活动；不自动唤醒、解锁或修改系统超时。

面板黑色不等于锁屏。电源键锁屏仍可能使某些App停止交互；离开设备时应正常锁屏。关闭相关应用窗口会沿用scrcpy恢复面板的逻辑。多个窗口共享手机面板，恢复或关闭其中一个会话可能使屏幕亮起。本次改动已编译，实际OEM兼容性仍需手动验收。

文件权限与快捷方式修复

生成 EXE 会在构建和发布后修正为普通用户的 Medium 完整性。快捷方式直接使用 Windows Shell API 创建、复制和定位，不需要管理员权限。若 AppData 不可写，数据回退到程序目录的 virCre-data；已有回退设置继续使用该目录。运行错误记录于实际数据目录的 logs/desktop.jsonl。

快捷方式的 App 图标保存在 %LOCALAPPDATA%\virCre\shell\shortcut-icons；链接和拖拽中间文件也使用该目录下的独立子目录。旧版空白图标链接可在新版中重新创建，新链接不会覆盖旧文件。此位置需要当前用户可写。
