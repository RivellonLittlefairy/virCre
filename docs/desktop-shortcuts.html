手机应用，拖到桌面

应用列表显示手机中的原始图标，收藏和主题在重启后保留。把应用卡片拖到桌面，或右键选择“创建桌面快捷方式”，即可生成带应用图标的 Windows 快捷方式。

使用

  1. 连接 Android 16 手机，完成 ADB 调试授权。请保留完整发布目录；ADB 和 scrcpy 已内置，不需要单独安装或配置 PATH。
  2. 启动 VirCre.Desktop.exe，选择手机并等待列表与真实图标加载。点击星标收藏，设置页可选系统、浅色或深色主题。
  3. 从卡片的图标、名称或空白区域拖到桌面空白处；不要从星标或“打开应用”按钮起拖。也可以右键卡片选择“创建桌面快捷方式”。
  4. 双击桌面的快捷方式，virCre 自动识别对应手机，并为该应用打开独立窗口。主程序已运行时复用原进程；同设备同应用已打开时切回原窗口。
  5. 手机离线、未授权、应用已卸载或快捷方式参数损坏时，主界面显示原因。它不会替用户确认手机权限或配对。

无线 ADB 地址变化时使用手机硬件标识重新匹配。无法读取稳定标识的手机暂不能创建自动连接快捷方式，避免误连另一手机。程序目录应固定；移动或删除该目录后，需重新创建链接。快捷方式不会把 Android 应用安装到 Windows，也不复制应用账号或数据。

设置与缓存

位置用途
%LOCALAPPDATA%\virCre\settings.json收藏包名、主题和格式版本；串行原子写入，损坏时使用默认值并提示。收藏跨手机共用，只展示当前已安装的匹配应用。
icons\设备哈希\代次96×96 PNG，每台手机通常保留上一代和当前代，刷新时清理旧代次。与手机主题包不同，使用应用自身资源；个别异常图标降级占位。
%LOCALAPPDATA%\virCre\shell\shortcut-icons\链接引用的 ICO，按图标内容去重并持久保存。删除这些文件会让已有快捷方式失去图标。
%LOCALAPPDATA%\virCre\shell\drag\拖拽生成的临时 .lnk；每次拖拽清理，最多保留 30 次，并清理超过 7 天的中间目录。桌面复制出来的链接不受影响。

程序会通过已授权 ADB 推送一个只读 dex 图标导出器，无需安装 APK 或 root。PackageManager 读取图标资源，Android Canvas 渲染 PNG 后传回 Windows。命令完成后删除手机临时 jar；本地读取有超时，手机进程也有 45 秒自退出保护。它不会修改手机系统主题、全局权限或第三方 APK。

开发与发布

pwsh -File .\tools\Start-Desktop.ps1
pwsh -File .\tools\Publish-Desktop.ps1

构建需要 .NET SDK 8、Android SDK API 36、Build Tools 和 JDK 11 以上。构建脚本默认读取本机 Android Studio 的 JBR 和 %LOCALAPPDATA%\Android\Sdk；独立构建可通过 Build-IconAgent.ps1 的 -Java/-Sdk 参数指定。发布目录 out\desktop-release 自带 .NET 与 Windows App SDK 运行依赖以及图标 dex；ADB、scrcpy、配套 server 和 DLL 位于 runtime/scrcpy；首次构建会下载并校验固定版本。源码位于 third_party/scrcpy，当前内置运行时是官方原版，尚未包含中文输入改动。版本与来源。

文件权限与快捷方式修复

生成 EXE 会在构建和发布后修正为普通用户的 Medium 完整性。快捷方式直接使用 Windows Shell API 创建、复制和定位，不需要管理员权限。若 AppData 不可写，数据回退到程序目录的 virCre-data；已有回退设置继续使用该目录。运行错误记录于实际数据目录的 logs/desktop.jsonl。原因、修复与测试记录。

快捷方式的 App 图标保存在 %LOCALAPPDATA%\virCre\shell\shortcut-icons；链接和拖拽中间文件也使用该目录下的独立子目录。旧版空白图标链接可在新版中重新创建，新链接不会覆盖旧文件。此位置需要当前用户可写。
