Android 版本兼容说明

virCre 按手机系统版本选择应用启动模式。普通模式通过 scrcpy 创建独立应用显示，不依赖虚拟摄像头所需的 Android 16 接口。

手机系统应用窗口桌面画面虚拟摄像头
Android 16 / API 36 及以上支持普通模式按设置启用，仍取决于系统及应用兼容性
Android 10～15 / API 29～35作为普通模式兼容目标自动禁用
Android 9 / API 28 及以下不支持当前独立应用窗口方案不支持

本次改动通过编译与静态检查交付，没有自动启动或操作手机应用，也没有执行运行时测试。Android 10～15 的实际窗口、输入和厂商系统兼容性仍需真机确认；最低 API 声明不代表所有应用均已验证可用。

使用方式

连接手机并刷新设备后，程序读取系统 API 版本。Android 10～15 手机从应用列表或桌面快捷方式启动应用时，均自动使用普通模式。设置页的虚拟摄像头开关显示为关闭且不可修改，并说明当前设备不支持该功能。

这一限制仅对当前手机生效，不会修改已保存的相机默认设置。切换至 Android 16 或以上手机后，恢复显示原有设置。已有应用窗口保持启动时的模式；其他手机上正在运行的相机会话仍可调整目标帧率。

应用列表、图标、缓存、收藏和快捷方式沿用现有实现。窗口支持鼠标和电脑键盘输入，中文继续使用电脑输入法。普通模式不将电脑桌面画面送入相机，应用使用物理相机的行为由手机系统和应用决定。

系统版本读取失败时，应用列表可以保留，但新窗口不会猜测系统版本后启动；请检查 ADB 连接并刷新设备。Android 9 或以下手机会在启动时收到版本要求提示。

构建边界

应用目录导出器和内置 scrcpy 服务端均以 API 29 为最低运行版本。虚拟摄像头保留 API 36 检查，只有支持的设备会进入该分支。独立构建的相机代理仍要求 API 36。

构建仍使用 Android SDK API 36；编译 SDK 与最低运行版本分别定义。修改最低运行版本后，需要重新构建内置 scrcpy，不能仅替换桌面程序。自定义运行时清单记录 androidMinApi=29 和 virtualCameraMinApi=36，桌面构建会拒绝缺少这些版本声明的旧运行时。

手动验证建议

  1. 在 Android 10～15 手机上刷新设备与应用，确认应用名称、图标和缓存正常；在设置中确认虚拟摄像头已自动禁用。
  2. 从应用列表打开应用，检查画面、鼠标点击、滚动，以及英文、数字和电脑输入法中文输入。
  3. 关闭窗口与主程序，通过已有桌面快捷方式打开应用，确认直接进入普通窗口。
  4. 切换至 Android 16 手机，确认之前保存的相机开关状态未被覆盖；新窗口按该设置选择模式。
