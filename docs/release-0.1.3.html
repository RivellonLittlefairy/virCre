virCre 0.1.3

2026-10-21 · Windows x64 · 文件版本 0.1.3.0

本版将普通应用窗口的兼容目标扩展至 Android 10，处理同一手机的双连接重复显示与相机关窗误报，并为桌面程序加入统一图标。

更新内容

  • Android 10～15 手机自动使用普通应用窗口，虚拟摄像头会被禁用，设置页显示版本限制。应用列表和桌面快捷方式使用同一套判断；切换至 Android 16 手机后，仍保留原有相机设置。旧系统的实际兼容性仍需真机确认。
  • 同一手机同时通过 USB 和无线 ADB 连接时，按已确认的硬件标识合并为一个设备，新窗口优先使用在线 USB 连接。刷新后保留所选手机，并复用该手机已有的应用窗口。已有会话不会在连接之间自动迁移；无法确认身份的连接不会仅凭机型合并。
  • 修复主动关闭虚拟摄像头窗口时的错误提示：程序收到正常退出事件后先停止桌面采集，避免将随后断开的相机通道误判为异常。真实的非零退出码仍会保留。
  • 新增蓝青色“窗口与手机”图标，统一用于 EXE、窗口、任务栏和安装器。手机应用快捷方式继续使用各应用自身的图标。
  • 统一版本来源：程序、安装器和发布脚本默认读取根目录的 VERSION 文件，界面显示程序集中的版本，避免升级时遗漏某处版本号。
  • 重写 README，前半部分说明连接、输入、快捷方式及相机使用，后半部分概括技术原理。发布文档仅收录已纳入 Git 的文件，避免包含本地未提交的设计草稿。

下载与升级

  • 安装版：virCre-0.1.3-win-x64-setup.exe。先关闭 virCre 及其手机应用窗口，再运行安装器。默认安装到当前用户目录，通常不需要管理员权限。
  • 便携版：virCre-0.1.3-win-x64-portable.zip。完整解压后启动 VirCre.Desktop.exe，请保留整个目录。更换程序位置后需重新创建手机应用快捷方式。
  • 文件校验：virCre-0.1.3-SHA256SUMS.txt。

电脑需要 Windows 10 2004（19041）及以上的 x64 系统。普通独立窗口以 Android 10（API 29）及以上为兼容目标，虚拟摄像头需要 Android 16（API 36）及以上。ADB、修改版 scrcpy 和桌面运行依赖均已内置。

设置、应用缓存和图标保存在当前用户的本地数据目录，卸载时默认保留。无线 ADB 仍需用户先完成配对和连接。

已知限制与验证范围

同时仅支持一个启用虚拟摄像头的应用窗口，实际相机帧率取决于电脑、手机和连接状况。应用窗口不转发手机声音。手机真正休眠或锁屏后，部分应用控件仍可能不响应输入。

本次发布执行编译、版本、图标资源和分发文件校验；发布包包含许可证、第三方许可及对应源码材料。未自动运行安装器、运行时测试或操作手机应用。Android 10～15、双连接合并、关窗提示，以及安装升级交互仍需手动确认。安装包未进行代码签名。
