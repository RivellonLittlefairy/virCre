在电脑上独立使用手机 App

2026-10-18 · 工程首页 · 真实目录读取 · 阶段计划

应用列表由程序实时从所选手机读取。现在可以双击应用卡片或点击“打开应用”，由官方 scrcpy 在新的 Android 显示上启动该 App，并提供独立 Windows 窗口。

使用

cd C:\Users\msf\AndroidStudioProjects\virCre
pwsh -File .\tools\Start-Desktop.ps1
# 已构建后：
pwsh -File .\tools\Start-Desktop.ps1 -NoBuild
  1. 在左侧选择已授权手机，等待真实应用列表；支持名称与包名搜索。
  2. 双击卡片的空白/名称区域，或点击“打开应用”。星标按钮仅收藏，双击星标不会打开应用。
  3. 同一手机的同一包名在启动中和运行中都只管理一个窗口；重复打开会切回已有窗口。Windows 拒绝前台激活时，界面会提示从任务栏切回。
  4. 不同 App 可同时独立开窗。“运行中”展示本工具打开的窗口，可切回或关闭。切换所选手机不会关闭已有窗口；运行记录按原设备保留。
  5. 手动关闭 scrcpy 窗口会移除运行记录；设备断连导致窗口退出时会提示异常结束。不会自动重连或重新打开。
  6. 关闭主界面时会取消启动、停止目录读取并关闭本工具拥有的 App 窗口。若关闭失败，保留错误提示和所有权；可先关闭残留窗口，再点击标题栏关闭按钮重试。

边界

App 仍在手机运行，使用手机已有账号和数据。独立窗口不等于应用双开；Android 可能移动已有任务。副屏兼容性、系统提示与主屏影响因 App 而异，不能保证所有 App 支持或完全不影响手机实体屏幕。当前关闭音频转发，键鼠使用 scrcpy 默认输入控制。

真实应用图标、收藏/主题持久化、同包多实例和音频不在本轮。虚拟摄像头仍是显式 -CameraLab 进入的内部实验，普通 App 启动不要求安装测试 APK、CDM 或相机探针授权。

实现

模块行为
AppWindowManager按(serial,package)先登记启动中，再启动进程。30秒窗口启动期限；失败保留清理错误或释放记录，后续可重试。从进程创建起观察退出，避免失败残留进程退出后留下死记录。
ScrcpyWindowHost显式 serial、精确包名、--new-display=1080x1920/420、--no-audio、--display-ime-policy=local；不使用 + 强制停止前缀。用参数数组启动，后台无额外控制台，scrcpy 应用窗口正常可见。
关闭与激活只处理本工具持有的进程。先请求正常关闭，8秒未退出才终止该进程树，并等待退出。窗口激活前检查窗口进程归属并恢复最小化；激活失败不会谎报成功。
UI卡片携带来源 serial；点击时核对当前设备与目录，避免旧卡片被当作新设备 App。运行列表使用不可变窗口快照并通过 DispatcherQueue 更新，独立于当前目录。

实测与回归

检查结果
真机并行vivo V2458A / Android 16。设置 com.android.settings、计算器 com.android.bbkcalculator 同时出现两个独立 Windows 窗口；最终复测 Android displayId=43、44，均不是默认显示0。
双重证据ADB activity 元数据分别包含对应 App 和显示；scrcpy 日志解析得到同样的43、44。曾发现把1080宽度误读为显示ID，新增回归并修复为解析括号内id字段。
复用与关闭重复打开设置返回同一会话ID，窗口数量仍2；关闭设置后计算器仍被管理；StopAsync 后本工具窗口记录和进程均结束。
自动行为测试覆盖参数身份、同包启动中/运行中去重、不同App、外部退出、失败重试、启动取消/超时、关闭失败继续受管理、退出重试清理；独立审查新增的两个重要边界均先复现失败再修正通过。
重要审查修复启动失败且清理失败后，进程后来退出会自动移除记录并允许重开；正在关闭的窗口明确提示等待，不能误报复用成功。
构建WinUI 3 构建0警告、0错误；Presentation、Launcher、既有VirCam核心回归通过。

主界面点击核验已完成：从实时目录搜索 com.android.settings，点击打开后出现“设置 · V2458A · virCre”窗口；运行中列表正确显示设置、V2458A、运行状态与切回/关闭按钮，UI对应displayId=45。点击列表关闭按钮后，设置窗口消失，主界面恢复“还没有打开的应用”；ADB活动显示仅剩默认Display #0，Windows没有残留scrcpy进程。最小化恢复、键盘输入落点与双击手势未另做专项自动化验收，打开按钮与关闭按钮已实点验证。

本地自动验证日志保留在 .superpowers/sdd/winui-shell/windows-live-final.log 等忽略目录，内容为测试结果、显示ID、数量和状态，不记录手机画面、输入内容或应用账号信息。

真实多手机并发、长时间运行、所有第三方 App 兼容性、混合DPI跨屏和200%文字仍未全面验证。小屏高DPI初始窗口高度可能超工作区的既有问题留待布局调整。没有把本次两个系统 App 的结果推广为所有 App 可用。
