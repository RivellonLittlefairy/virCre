主窗口改版实现说明

依据 主界面设计方案 02 · A 轻量横卡，在现有 WinUI 3 主窗口中实现布局与交互。继续使用真实手机目录及现有缓存、窗口、快捷方式和虚拟摄像头服务。

2026-10-22 · 随 virCre 0.2 发布；本次改动集中在主界面，手机运行时沿用 0.1.3。

设计对应

设计实现
紧凑窗口默认 960 × 600，最小 720 × 520 个逻辑像素。按显示缩放换算窗口尺寸，并限制在工作区内。
左侧导航180px 侧栏，保留全部应用、收藏、运行中和底部设置。计数分别来自当前设备完整目录、当前目录收藏数和全部运行窗口数，不受搜索结果影响。
顶部设备栏设备选择、Android 版本、USB/无线连接方式、连接状态及刷新入口。启动继续优先使用目录缓存，只有主动刷新才重新读取应用。
应用区域仅保留搜索和卡片列表。默认三列，按可用宽度调整列数；列表独立滚动。窄窗口缩小留白并折叠刷新按钮文字。
轻量横卡约 72px 高，46px 图标、名称和操作提示。包名保留在悬停提示及搜索中。打开按钮铺满卡片，收藏按钮独立叠放；收藏区域之外均可单击打开或切回窗口。卡片不使用悬停变色、按压阴影或过渡动画，保留键盘焦点提示。搜索框采用等宽细边框，去掉底部渐变强调线。
独立收藏收藏按钮与打开按钮分开，支持键盘操作。为保证第一次触摸也命中，收藏区域统一采用 44 × 44px，略大于桌面稿的 40px。
快捷方式继续支持右键创建和拖出卡片。鼠标移动超过 8px 后才接管指针，取消打开按钮的点击，再进入原有系统文件拖放流程。触屏保留列表滚动。
运行中集中展示窗口、缓存图标、设备、状态及模式。保留相机画面控制、切回与关闭，切换所选手机不会丢失其他手机的运行窗口。
设置按行展示外观、虚拟摄像头、目标帧率与版本说明。保留跟随系统、浅色、深色、Android 兼容性提示和已有设置持久化。
空态与提示区分未连接、读取中、读取失败、搜索无结果、收藏为空及无运行窗口，提供刷新、清空搜索或查看全部应用。底部使用固定 38px 的单行状态栏，有消息时替换设备状态，不额外压缩列表。普通消息 6 秒后恢复最新设备状态；错误和带恢复操作的消息保留到关闭或被新消息替换。长消息可悬停查看完整内容。
主题独立的浅色、深色和系统高对比度资源。设备栏、应用区和底部状态栏使用统一底色，以细线和留白划分区域，取消上下拼色。实际主题切换、系统高对比度及跨屏缩放效果由人工验证。

代码位置

  • desktop/VirCre.Desktop/MainWindow.xaml：主布局、卡片、运行列表、空态与设置。
  • desktop/VirCre.Desktop/ShellStyles.xaml：主题颜色与按钮样式。
  • desktop/VirCre.Desktop/MainWindow.xaml.cs：窗口尺寸、导航计数、状态和自适应布局。
  • desktop/VirCre.Desktop/MainWindow.Drag.cs：点击与拖拽手势的指针归属。
  • desktop/VirCre.Presentation/ShellViewModel.cs、AppCard.cs、RunningWindowCard.cs：目录计数、当前设备运行标记、运行列表图标投影；均不增加手机读取。

交付与验证边界

安装包和便携包见 0.2 更新说明。便携版完整解压后，从该目录启动 VirCre.Desktop.exe，并保留整个目录。分发包携带现有 Custom scrcpy 运行时，保留已有中文输入和虚拟摄像头功能。

执行 Release 构建与自包含发布，并检查差异和输出文件。按用户要求，不运行自动化测试、不自动启动桌面软件、不操作手机。编译成功仅证明代码和 XAML 可构建；界面效果、真实输入、拖放和设备交互仍由用户验证。

人工验收

  1. 关闭原来的主程序后，启动 0.2 版本的程序。核对默认三列卡片、顶部设备栏及底部设置。
  2. 调整窗口尺寸、切换浅色/深色/跟随系统，并检查长应用名、搜索、收藏计数和空状态。
  3. 单击卡片打开应用，再次单击切回。点击星标应仅改变收藏；鼠标拖出卡片应仅创建快捷方式。
  4. 在运行中页面检查图标、切回、关闭和相机画面控制。切换设备后，其他手机的窗口应仍可管理。
  5. 核对设置保存、相机开关、帧率即时更新、断开连接后的提示及重新刷新后的恢复。
