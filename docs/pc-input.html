Windows 画面输入

2026-10-18 · 工程首页 · 设计与协议 · P0 记录

已实现 Windows 控制程序：选择图片或框选固定桌面区域，经 ADB 送入 Android 16 虚拟相机。两张文件二维码及一个真实桌面区域的 Camera2 读回已验证。首版复用官方 scrcpy 5.0.1，没有修改或 fork scrcpy。

启动和使用

依赖 Windows、.NET 8 SDK、PowerShell 7、PATH 中的 adb 与 scrcpy，以及已授权连接的 Android 16 手机。首次运行或修改 Android 代码后先构建 APK：

cd C:\Users\msf\AndroidStudioProjects\virCre
pwsh -File .\tools\Build.ps1
pwsh -File .\tools\Start-Desktop.ps1
  1. 在 Windows 控制窗口刷新设备，确认目标手机序列号。多设备时必须明确选择。
  2. 首次安装或 Android App 更新后勾选“更新测试 APK”。本次已安装的版本可取消勾选，然后点“启动手机会话”。手机如有安装确认，需手动允许。
  3. 在置顶的“VirCam-P0”投屏窗口允许摄像头。每次新建虚拟设备可能单独询问。保持手机解锁和测试 App 前台；探针离开前台会停止读取，可回到探针点击“开始读取”。
  4. 点击“选择图片”，或“框选桌面区域”并拖选区域。将控制窗口和投屏窗口移出采集区，再点击“开始输入”。
  5. 电脑预览显示本次已发送并获接收端确认的内容；投屏预览显示 Camera2 实际读回的灰度图。ACK 表示接收成功，不能单独证明 Camera2 读回成功。
  6. “暂停输入”停止供图并清空电脑预览。手机显示“PC INPUT PAUSED”，表示没有有效的新 PC 输入；连接后尚未点击开始、主动暂停、断连或输入过期都会出现该图。
  7. “停止会话”、关闭本次 scrcpy 或关闭控制程序进入清理。日志按钮可打开证据目录。若提示清理失败，应查看 result.json 和 session.json；不要把失败当成正常停止。

调试程序单次会话最长 600 秒，到时需手动重新启动。连接断开后不自动重连或恢复输入。测试 App 预览使用 Y 平面，因此显示灰度；桌面传输本身为 PNG 彩色图。

当前边界

固定区域读取 Windows 当前可见像素。其他窗口、游戏、悬浮图层覆盖时，也会进入采集图。程序能拒绝与自身控制窗口及本次 scrcpy 窗口相交的区域，不能识别所有外部遮挡。移动窗口不改变已选区域坐标；显示器布局变化后应重新框选。

尚未实现“让投屏框自动跟随，并取它背后的桌面内容”。该能力需要另行设计 Windows 捕获与排除窗口机制。当前也未验证第三方扫码 App、全局物理相机替换、十分钟连续稳定运行或五次完整会话启停；下文五轮指同一会话内的输入切换。

实现与检查

输入保持比例并留边至 640×480；PNG 上限 1 MiB。64 字节大端协议校验版本、会话、deviceId、序号和尺寸；只连接 127.0.0.1 的指定 ADB 转发。单个在途帧等待 ACK，交换超时 3 秒；Android 只保存最新图，暂停、断连或接收端超过 1500 ms 无新图时清空。消费者端另有相机及 UI 缓冲，因此这些设置不能视为端到端延迟保证。

dotnet build .\desktop\VirCam.Desktop --nologo
dotnet run --project .\desktop\VirCam.Tests
pwsh -File .\tools\Test-Tools.ps1
.\android\gradlew.bat -p android :app:assembleDebug :app:testDebugUnitTest :app:lintDebug

Windows 构建 0 错误、0 警告；协议、输入切换代际、清理结果传播检查通过。Android 构建、10 个单元测试及 lintDebug 任务通过；lint 仍有隐藏 API 及依赖等警告，不视为零警告。PowerShell 检查覆盖证据过滤、进程超时、启动前与运行中取消、动态转发结果丢失后的精确回收及其他会话保护。

独立代码审查及复审已完成：修复旧输入发布、授权等待不可取消、清理失败被隐藏，以及创建转发结果丢失后的资源遗留。复审无新增 Important/Critical。shell 进程的文字占位图使用像素字模，避免 Canvas/Typeface 初始化造成原生断言崩溃。

源码入口

desktop/VirCam.Desktop/ 为 Windows UI、图片与桌面采集；desktop/VirCam.Core/ 为协议、背压和会话结果校验；tools/Start-Desktop.ps1 为桌面入口；tools/Start-P0.ps1 负责设备会话与精确清理；Android 的 shell/DesktopReceiver.java、shell/EglPattern.java 接收并供图，probe/CameraReader.kt 提供实际读回证据。
